🧱 ¿Qué es esto, en una frase?

Una app Laravel donde un admin sube ejemplos de "entrada → reporte que quiero", configura reglas (palabras prohibidas, longitud) y deja entrenado un "tipo de reporte". Después, cualquier usuario sube archivos nuevos y recibe un reporte hecho por OpenAI que ya respeta esas reglas — el sistema vigila, corrige y limpia la salida antes de entregarla.

🧪 Defensa en 3 capas

  1. Instrucciones: el system prompt le dice a la IA qué no hacer.
  2. Validación + reintento: si la salida viola reglas, el código le manda feedback y reintenta (hasta 2 veces).
  3. Saneo determinístico: aunque la IA insista, el código reemplaza palabras prohibidas y corta el texto al límite. Esta capa NO depende de la IA.
Generado a partir de app/Services/AITrainingService.php, OutputValidatorService.php y PromptParserService.php. Abrí este archivo en cualquier navegador — funciona sin servidor.
